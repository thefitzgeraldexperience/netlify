# AGENTS.md

Online store for **The Fitzgerald Experience** (smoked salts + body balms). TanStack Start on Netlify, PayPal checkout, orders in Netlify Database.

## Architecture

- `src/data/products.ts` — the product catalog (static, typed). Single source of truth for names and prices. Product `id` is a URL slug.
- `src/data/store.ts` — store name, currency, shipping rules (`shippingFor`), `formatPrice`, and `imageUrl` (builds Netlify Image CDN URLs — always use it for `<img>` so full-size PNGs are never shipped).
- `src/lib/cart.tsx` — `CartProvider` / `useCart`, React context persisted to `localStorage` (`fitzgerald-cart`). Mounted in `__root.tsx`.
- `src/lib/checkout.ts` — TanStack Start server functions:
  - `getPaypalConfig` — exposes the (public) client ID and whether checkout is enabled.
  - `createPaypalOrder` — validates the cart with zod, **recomputes totals from the catalog** (never trust client prices), creates a PayPal order, inserts an `orders` row with status `created`.
  - `capturePaypalOrder` — captures payment, sets status `paid`, stores payer + shipping address.
  - `getOrderSummary` — limited, non-PII summary for the confirmation page (paid orders only).
- `src/lib/paypal.server.ts` — minimal PayPal REST client (OAuth token + POST). Imported dynamically inside handlers so it stays server-only.
- `src/components/PayPalCheckout.tsx` — loads the PayPal JS SDK once and renders Smart Buttons wired to the server functions.
- `db/schema.ts`, `db/index.ts` — Drizzle schema and client (`drizzle-orm/netlify-db`). Migrations in `netlify/database/migrations/` generated with `npx drizzle-kit generate --name <name>`; never hand-edit or apply them.

## Routes

`/` home + shop grid · `/products/$productId` · `/cart` (PayPal checkout) · `/checkout/success?order=<paypalOrderId>`

## Environment

`PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `PAYPAL_ENV` (`sandbox` | `live`, default sandbox). Without both keys the cart shows a "checkout opening soon" notice.

## Conventions

- Tailwind 4 with theme tokens in `src/styles.css` (`char`, `smoke`, `ember`, `cream`, `ash`; `font-display` = Barlow Condensed, normal + italic, the brand font, sans = Figtree). Dark, smoky aesthetic.
- `@/` alias → `src/`. Imports from `db/` use relative paths.
- Money is always integer cents.
- All display names use the "Line | Name" format via `fullName()` (e.g. "The Body Experience | Rally Recoup", "Maybe Don't | Mild Heat Smoked Salt").
- The four smoked salts share one cold-smoked salt base and differ by heat level (`heat`: none → insane, badge colors in `heatColors` match the jar label borders). Names, net weight (4 oz / 113g), and ingredients come from the owner's label sheets; product images in `public/img/salt-*.png` are crops of those labels. The $12 price and descriptions are starting copy.
- Balm images in `public/img/balm-*.png` are the owner's 2.5" round lid labels shown on a tin. The balm labels carry no size, ingredients, or price, so the 2 oz tin, $16 price, and descriptions are starting copy.
- `src/routeTree.gen.ts` is generated by the router plugin and gitignored.
